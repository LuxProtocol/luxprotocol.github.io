# Lux Protocol – Aerial Matrix

## Overview

This repository contains the source code for our capstone project website.

The website presents:

* Project overview and purpose
* Team members and roles
* Subsystem responsibilities
* Design documentation and presentations

---

## Website

The live site is hosted here [HERE](luxprotocol.github.io/)

## Repository Structure

Structure
* index.html – Main website entry point
* assets/ – Images and media
* styles/, style.css – Styling
* js/ – JavaScript functionality
* documents/ – Design documents
* presentations/ – Design review slides
* blogs/ – Blog/update content

## Notes

All required capstone materials and more (design reviews, final document, etc.) are accessible through the website. This repository is intended for maintaining and updating the site content.
